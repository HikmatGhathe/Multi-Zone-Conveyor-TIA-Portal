# Background and provenance

## Amazon RME internship (April–June 2025)

The author reports working on a conveyor project during an Amazon Reliability Maintenance Engineering internship in Horn-Bad Meinberg, including Siemens TIA Portal, SCL/KOP, troubleshooting and real-plant commissioning/support.

## Independent reconstruction (November 2026)

This GitHub repository is an independently rebuilt multi-zone conveyor concept using TIA Portal V21: reusable zone FBs with instance DBs, barcode routing, pneumatic diverter, machine supervision, diagnostics, motor interlocks, and WinCC Unified overview.

**Not included:** original Amazon PLC project files, plant I/O maps, company network details, or internal documentation.

**Verified in current materials:** offline PLC and HMI compilations without errors, TIA Portal screenshots and the shared FB_ZoneControl body. **Not verified:** an end-to-end functional PLCSIM run.
