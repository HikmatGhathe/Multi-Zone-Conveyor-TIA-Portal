# Project background

## Amazon RME internship (April–June 2025)

I developed and implemented conveyor-control work during my **Amazon Reliability Maintenance Engineering (RME) internship in Horn-Bad Meinberg**. My responsibilities included programming with **Siemens TIA Portal using SCL and KOP**, handling sensor and motor-control signals, troubleshooting, and **commissioning my control work on a real conveyor installation**.

## Multi-Zone Conveyor portfolio (2026)

This repository presents my Multi-Zone Conveyor Routing & Sortation project in TIA Portal V21, including reusable zone FBs with instance DBs, barcode routing, a pneumatic diverter, central machine supervision, diagnostics, motor interlocks, and a WinCC Unified overview. The public source files and visual documentation are authored for this portfolio; they are not copied from Amazon's internal PLC software.

**Not included:** original Amazon PLC project files, plant I/O maps, company network details, or internal documentation.

**Engineering materials:** TIA Portal PLC and HMI compilation screenshots, HMI/network configuration, and the documented zone-control SCL implementation. Functional runtime tests are tracked separately in the test plan.
